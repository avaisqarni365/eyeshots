# EyeShots Web Client (Next.js 15)

The user-facing web portal for EyeShots, featuring dedicated programmatic SEO landing pages, client-side WASM execution via `pdf-lib`, and interactive editing with `PDF.js` and `Fabric.js`.

---

## 🛠 Features
- **Client-Side WASM Fast Path:** Zero-server-cost execution for Merge, Split, Rotate, Delete, and Stamping.
- **Dedicated SEO Pages:** Pre-rendered pages for all 35+ tools (`/merge-pdf`, `/compress-pdf`, `/pdf-to-word`, etc.).
- **Interactive Visual Editor:** In-place page canvas, signatures, whiteout redaction, and annotation flattening.

---

## 🚀 Getting Started
```bash
npm install
npm run dev
```
Visit `http://localhost:3000` to interact with the application.
